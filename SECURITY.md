# Security policy

## Report a vulnerability

Please do not open a public issue or pull request for a security problem.

Private vulnerability reporting is currently switched off on this repository, so the
GitHub advisory form (<https://github.com/dob-0/di.iiii/security/advisories/new>) may not
accept a report yet. Today, open a public issue that says only "I have a security report,
please open a private channel" and put no details in it. We will answer there and move the
conversation somewhere private. When private reporting is switched on, this file will
name that route.

Helpful to include: what you did, what you expected, what happened, the address or
version, and whether a space or its guests are exposed.

## Supported versions

- The `main` branch, which is what runs on diiii.xyz.
- The newest release a machine installed with `di up` can update to.

Older releases are not patched. Update to the newest one.

## Disclosure and timeline

- Reports are read and answered as soon as the maintainers can.
- We tell you when a fix ships.
- Please keep the details private until the fix is live. Then we publish the advisory and
  credit you, if you want that.

Do not test against spaces or guests that are not yours.
