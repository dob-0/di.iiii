What Raw Is Now

2026-08-20 · audited at origin/dev 951da5b8 — the exact build live on staging (deployed 00:05) · five code auditors + a live look at staging.di-studio.xyz/open/raw, desktop and phone

Raw has just come out of an eighteen-PR rebuild (#171–#188) and the product it is today is not the product the last audit described. The room-as-backdrop question is settled — by deletion. The desk is flat paper, always; the room is a window you open. Camera, /out, Monitor and Geo wiring are real. What did not move: any of the ranked operator cheap wins, any of the seven architecture walls, and the in-product Help — which still teaches a product that no longer exists.

01The shape of the wave

The wave's through-line was one decision made three times in two days: always-on backdrop (#174) → only-with-content (#179) → never a backdrop (#188). #188 is the final word and it is a full reversal, not a refinement — scopeHasRoomContent and roomContent.js are deleted outright. The room is now reachable exactly three ways: the resizable Scene window, the fullscreen Room (now a palette command), and /out.

Also gone: the 08-18 starter desk. starterWorkspace.js was deleted by #176's cut list; a first visit now shows flat paper, "Double-click to place your first node", and a "Make me a scene" button that only offers itself on a truly blank root desk (#186 stopped it trespassing into containers). First-visit word count went 71 → 18.

What the wave shipped that is real, verified in code end to end:

  • Node anatomy (#171/#172) — the "what is it made of" sheet, quoting real source lines from a CI-gated generated manifest.
  • Constructor (#173) — a node made of nodes; geometry descriptor with depth/piece caps.
  • Geo (#177) + Geo output (#186) — a plain spatial container that now emits its children as one recursive geometry group; Geo→Merge and Geo-in-Geo work. The geometry port type went from unused to five real carriers.
  • Camera (#181) — world.camera, ●-explicit activation only, drives the eye every frame; a Time→Sin dolly works by wiring.
  • /out (#182) — chromeless read-only room per scope, op-log/storage-event live, wake lock; respects the authored camera by construction.
  • Monitor (#183) — stream.monitor implemented (2D-canvas copy, no extra WebGL context).
  • De-fight (#187) — spatial cards drop below their click; duplicate selection pills gone from composite views.

02Seen live on staging

Looked at with my own eyes (headless Chromium, desktop 1440×900 and iPhone-13 emulation): the clear desk renders as designed on both; double-tap on the phone emulation opens the palette; the Room palette entry exists (second item), so the fullscreen Room is reachable on first visit — two of the old audit's worst findings no longer reproduce here.

Caveat kept honest: the code still has no dedicated touch double-tap handler — it relies on the browser synthesizing dblclick on a touch-action:none element. Chromium synthesizes it; the 08-20 human test on a real phone found it dead. Emulation cannot settle this — it needs one real-device look before "phone fixed" is claimed.

05The seven walls — all standing

  1. Clock is React state. No document-anchored clock shipped; useGraphClock is per-mount, with two independent owners inside one editor and a third in /out — the per-window Time phase offset is real, not folklore.
  2. No inter-frame state. Evaluation builds a fresh cache per pass; liveOutputs is an external-capture escape hatch, never written by evaluation. A lag node could not hold state today.
  3. No texture engine. Zero render targets in src/. All texture handling is pass-through display; stream.compositor/switcher exist only as port contracts.
  4. Three hand-written dispatchers. 30 cases in the runtime, 14 in the viewport, 16 branches in window routing — adding a type still means editing three files. Registry-colocation was recommended before op count grows; it grew (+3 types) without it.
  5. WebGL budget — the one partial breach. World panels mount per-scope only, none while fullscreen; Monitor deliberately costs no context. But N World nodes in one scope still open N canvases.
  6. Capture is window-local. Zero WebRTC anywhere; webcam/mic/MIDI live in the mounting component's state and cannot reach /out.
  7. Publish renders document.entities only. No nodes→entities path exists; a Raw graph published today is an empty or stale room. RawHub's own copy says the quiet part: "move stable work into Studio and publish."

Root causes cluster: walls 1/2/6 are all "anything that isn't the op-log lives in whichever component mounted it"; walls 3/4/7 are honestly self-documented via the authoringOnly gate rather than silently regressed.
