The one question that is yours, not mine

blocks rows 10–11 of the change list

Everything above assumes Studio is a room. But an unsigned spec in the repo proposes splitting the product across two hosts and names the creator host studio.di-studio.xyz — which makes Studio the name of the entire authoring side of the platform.

These cannot both be true. Answer it before any copy work, because it decides which word moves.docs/architecture/SPEC_url_architecture_and_tree_addressing.md §2.1 — status: DRAFT, unsigned
