B — The address carries it

Armenian lives at its own address: /hy/… in front of any path. The switch is a link to the same page in the other language, shown in the frame's top-left beside the name di.iiii, so it reads as part of where you are. A link you send carries the language with it, and search can index both.

Where it sits
Top-left, directly after the name di.iiii, in every frame: landing, /spaces, a space's frame strip, the Studio bar, the wiki. It is two links, not a toggle: EN → the path without /hy, ՀԱՅ → the same path with it. Query and hash are kept.
What it remembers, and how
The address is the memory: every link drawn inside a /hy/ page stays inside /hy/. A first-party cookie di_lang=hy (1 year, SameSite=Lax, set only when the visitor presses the switch) is read in exactly one place, the bare root /, which then offers “Հայերեն →” as a line under the header — it never redirects on its own. Signed in: the account also stores it, so emails and invitations di.iiii sends use the person's language.
What the address does
/hy/ prefix on every route: /hy/spaces, /hy/sample-space, /hy/sample-space/studio/…. English stays where it is today, unprefixed, so no existing link or printed QR code changes. Cost, plainly: hy must become a reserved space name (checked against the live spaces table before this ships), and the router has one more segment to strip on every route.
What it means for search
A subdirectory per language is one of the URL structures Google Search Central lists in “Managing multi-regional and multilingual sites” (beside country domains and subdomains; URL parameters it marks “not recommended”), and it is the only one of the three concepts that gives each language its own URL without a new domain. Each public page lists every version of itself in <link rel="alternate" hreflang="en" …>, hreflang="hy" and hreflang="x-default" → the English address; each version lists all the others and itself, as the “Tell Google about localized versions of your page” guide requires, or Google ignores the pair. Studio and other signed-in pages stay noindex.
A page with no Armenian yet
/hy/that-page still answers 200: frame in Armenian, body in English under one line: Այս էջը դեռ հայերեն չունի։ Ստորև՝ անգլերեն։ Until it has an Armenian body it is left out of the hreflang set and its canonical points at the English address, so search never shows an English page as “the Armenian one”.
How the work is left untouched
The prefix is read and stripped by the frame before anything else; the work is resolved from the remaining path and served byte-for-byte the same under both addresses. It is never told the language (no parameter, no message, no attribute), its container carries translate="no" against browser translation, and its own lang is the artist's. A space's front page that is already bilingual stays bilingual at both addresses.

Typeface: the platform's Inter is a latin subset (48,256 bytes) with no Armenian glyphs, so Armenian here falls back to the system font, as it would on the live site today. All Armenian copy in this sketch needs a native speaker's check.
