Where it sits
Top-right of every header (landing, /spaces, a space's frame strip, the Studio bar, the wiki), immediately left of the account. One component, one place. Both words are always shown, the current one filled cyan, so a visitor who reads only one of the two scripts can still find their way back.
What it remembers, and how
Per device: localStorage["di.lang"] = hy | en. Signed in: also saved on the account (serverXR user preferences), so a second device picks it up at sign-in; the account wins over the device when they differ. First visit with nothing saved: English (what the site is today); the switch is the only way in — no guessing from the browser language.
What the address does
Nothing. /sample-space is the same address in both languages. A link someone sends opens in the receiver's own saved language, not the sender's.
What it means for search
Google Search Central ("Managing multi-regional and multilingual sites") recommends a different URL for each language version rather than cookies or browser settings, and notes its crawlers usually come from US addresses without an Accept-Language header; a crawler keeps no stored choice, so it sees English only. The Armenian frame is never indexed, and hreflang cannot be used — it needs a second URL to point at. Plainly: nobody finds di.iiii by searching in Armenian.
A page with no Armenian yet
The frame (bar, buttons, menus) switches anyway. The page body stays English, with one line on top in Armenian: Այս էջը դեռ հայերեն չունի։ Ստորև՝ անգլերեն։ (“This page has no Armenian yet. English below.”) The switch itself never hides or greys out.
How the work is left untouched
The switch only changes strings the platform owns. The work (a space's page, scene or iframe) gets no message and no attribute from it; its container carries translate="no" so a browser's own translate button on the frame cannot rewrite it either, and the work's lang is whatever the artist declared. A bilingual work, like a front page that carries Armenian and English side by side today, stays exactly as made.

Typeface: the platform's Inter is a latin subset (48,256 bytes) with no Armenian glyphs, so Armenian here falls back to the system font, as it would on the live site today. All Armenian copy in this sketch needs a native speaker's check.
