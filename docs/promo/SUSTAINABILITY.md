# Sustainability — the library model

di.iiii is built as collective infrastructure: like a public library, anyone can enter,
read, touch, and build on what's inside. The knowledge stays open; the income comes from
services around it, not from closing the shelves.

## What stays open, permanently

- **Code** — AGPL-3.0 (see `/LICENSE`). Anyone may read, use, modify, self-host. Anyone
  who hosts a modified copy must publish their changes back — the library grows, it
  cannot be quietly enclosed. As sole copyright holder, thedi.studio can additionally
  sell license exceptions or run commercial services; nobody else can close the source.
- **Formats & protocol** — the node document model, space bundles, REST/WS API stay
  documented and exportable. A creator can always take their spaces and leave.
- **Asset commons** — uploads to the shared commons default to CC-BY (uploader may pick
  another CC license). Creators always retain ownership of their own spaces/projects.
- **Published spaces** — public URLs stay free to visit, no login to view.

Follow-up owed: a short `/terms` page stating the above in plain words (pairs with the
`/privacy` routing item already open in CURRENT.md).

## How it eats (revenue lanes that don't close the library)

1. **Hosted spaces** — the free tier (3 spaces/account) already exists; paid tiers add
   more spaces, storage, custom domains, priority support. Self-hosting stays free —
   the paid product is convenience on the canonical host, not access.
2. **Exhibition commissions** — br_id_ge, WCC, Beyond Form are the precedent: building
   and operating an exhibition/experience for an institution or festival is paid work
   done *with* the open tool.
3. **Workshops & education** — the guest sandbox + communal Open Space + zero-install
   is a ready-made classroom; paid workshops for schools, festivals, residencies.
4. **Patronage** — GitHub Sponsors / OpenCollective for the platform itself; grants
   (digital heritage, Creative Europe-class programs) fit the manifesto's 30-year
   retrievability mission.
