# Promotion Plan

One promotable sentence: **di.iiii is a browser-native, collaborative WebXR authoring
platform — open a URL, build a 3D/AR/VR space with others in real time, publish it to a
public URL. No installs, no engine, AGPL open source, self-hostable — with real
exhibitions already running on it.**

## Audiences (ranked by fit today)

1. **New-media / XR artists & curators** — strongest fit: three live cultural projects
   (br_id_ge, WCC, Beyond Form), open-call pattern, communal live spaces, heritage
   framing. They need a compelling tool + examples, not pricing.
2. **Cultural institutions & festivals** — "exhibition in the browser, no app install,
   works on phones and headsets." Warm entries via Gyumri Art Week / WCC.
3. **Creative-coding / WebXR developers** — Three.js forum, WebXR Discord, r/WebXR.
   Care about: node model, GitHub-sync publishing, API, self-hosting, AGPL. Contributor
   pipeline.
4. **Educators / workshops** — guest sandbox + Open Space + zero install = classroom.
5. **AI-agent builders** — REST API + GitHub sync make di.iiii a 3D output surface for
   agents; niche but highly shareable (HN/X).

Deprioritized: general "metaverse" consumers, enterprise — nothing serves them yet.

## Phases

### Phase 0 — get promotable (before any post)
- [x] LICENSE (AGPL-3.0) + package.json license field — makes the landing's
      "Open source" claim true (commit `293e8faf`).
- [ ] **Demo recording (user)** — 60–90s screen capture: open URL → build → invite →

- [ ] Decide public repo face: make `dob-0/di.iiii` presentable (public-README as the
      repo face) — check nothing sensitive in history before publicizing.
- [ ] Push license commit to `dev` → `main` when ready.

### Phase 1 — communities (weeks 1–2)
Drafts in `drafts/`. Post order: Notations #2 announcement (event hook, Jul 20) →
Three.js forum Showcase → r/WebXR + r/threejs → Show HN. Each leads with a live space
URL — landing *inside* a shared space is the demo.

### Phase 2 — stakeholder mail (weeks 2–4)
Short personal notes (never newsletter blasts) to ~20–40 named people:
curators (Gyumri/WCC circle), digital-heritage orgs, XR festival open-call organizers,
WebXR advocates at browser vendors. Template + list: `drafts/stakeholder-mail.md`,
`drafts/stakeholders.md`. **Every send individually approved by the user.**

### Phase 3 — sustained beats
Each new exhibition (Notations #2 results, Beyond Form outcomes) = one post + one mail
round. News beats, not generic platform pushes.
