# Accessibility and performance — 2026-10-21

Agent #29 of `docs/ai/cloud-briefs/2026-10-13-pro-sweep.md` (owner N612: "find what is not professional, fix all of it"),
the browser-free part only. Base: `dev` at the commit this branch starts from (the brief's base branch is stale). Absorbs

## Method

- **Lint count.** `npx eslint src -f json`, jsx-a11y messages counted by rule and `file:line`, before and after.
- **Tests.** One vitest + Testing Library case per fix, run red against the unfixed source (source files stashed, tests kept)
  and green after. Plus `src/a11y.lint.test.js`, which runs ESLint's API on the five files and reads the resolved config.
- **Bundle sizes.** `npx vite build --manifest` on `dev` (the fix's source files stashed, so the numbers are dev's), then
  `node scripts/audit/bundle-sizes.mjs` (add `--json` for the raw rows). The script reads `dist/.vite/manifest.json`, never
  builds, and gives each emitted `.js`/`.css` file its raw bytes and gzip bytes (node zlib, level 9 — the server's own level
  may differ, so the served bytes can be a little larger). Kinds: `entry` (index.html), `lazy` (a dynamic-import target, named
  by its source module — the route chunks), `shared` (a chunk two or more importers share, named by its chunk name), `css`.
  **First load** = the entry and its static import closure: what the browser must fetch before the app runs. Node v22.22.0,
  Linux container, build time 11.2 s.

Either the entry stops importing it, or it is preloaded again. Not measured in a browser. | OPEN |
