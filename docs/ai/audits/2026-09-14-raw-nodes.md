## Legend for the "inside" columns

- **A** = entering shows an empty canvas. The "What it's made of" button opens NodeAnatomyPanel, but
  only while the scope is still empty (`RawGraphSurface.jsx:1230-1245`). The sheet is read-only text:
  ports with their current values, where a value came from, and the file and line range of the code
  (with "Show the lines" for runtime.js, nodeGraphRuntime.js and RawViewport.jsx).
- **A-gaps (std)** = no live preview, parameters can't be edited, values are text only (no scope,
  swatch or picture), no graph over time, no script.
- **W** = panel node. If its window is closed, "enter" reopens the window instead
  (`RawEditor.jsx:635-638`). Otherwise it enters an empty scope, then A.
- **T** = TopInsidePanel covers the whole graph: a 640x360 picture, the Camera section (camera
  only), a GLSL editor and a JS script editor (`TopInsidePanel.jsx`). It does not show the
  operator's parameters, its input/output ports, or Analyze's numbers.
- **C** = a container interior (real child nodes; doorways become sockets).
- "live-window" = an output that only exists while the node's panel window is mounted:
  same scope, visible, and not fullscreen (`windowLayout.js:55-68`, `if (isWorldFullscreen) return []`).

## Picture (9) — `src/project/tops/`

Shared facts:
- Picture `out` evaluates to `null` in the graph (`topRuntime.js:9`).
- The engine only reads wires that go from one operator's `out` to another operator's `a`/`b`
  (`useTopNetwork.js:27-29`).
- A Webcam, Video or Plane texture wire draws (texture to texture is compatible) but carries nothing.
- Parameters are `configInputs` (`topOperators.js` buildTopNodeTypes), so nothing can wire into them.
- The card shows TopThumbnail, the live picture, while TopNetworkFeed runs (`RawEditor.jsx:2553`).
- Anatomy: the manifest has no `computes` or `draws` for tops (`node-anatomy-lib.mjs:176-179`
  measures only the switch, RawViewport and RawEditor). render:'hidden' makes the sheet say
  "It is not drawn at all" (`NodeAnatomyPanel.jsx:217-219`), and Picture reads "nothing coming out".

## Cross-cutting defects (file:line)

1. **Cards show no values.** 38 number/logic/vector/colour types, and every device, are ports only
   (`RawGraphSurface.jsx:1452-1475`, `nodeRegistry.js:202-212`). No wire hover value either.
2. **The card preview is a still.** `now: 0` and no liveOutputs (`resolvePreview.js:30`). NO_PREVIEW
   covers Video, Model and Camera (`previewTypes.js:21-33`). Webcam, Monitor and Image have no picture.
3. **Two picture worlds that don't connect.** `topRuntime.js:9` returns `null` for `out`, and
   `useTopNetwork.js:27-29` only reads wires between two operators. Texture wires draw but carry nothing.
4. **Live inputs belong to their window.** `windowLayout.js:62` (fullscreen gives `[]`) and `:63-67`
   (scope + visible). The example closes every window (`allNodesExample.js:128`). Feeds for MIDI Out,
   Keyboard, Video, Sound and Tops keep running, so behaviour is inconsistent.
5. **The /out and public surfaces get `liveOutputs={null}`** (`RawOutSurface.jsx:94`,
   `PublicGraphSurface.jsx:45`), so no webcam, mic, MIDI or Analyze numbers on the output page.
6. **Port compatibility is too strict for a TD user.** number↔boolean and signal↔boolean are refused
