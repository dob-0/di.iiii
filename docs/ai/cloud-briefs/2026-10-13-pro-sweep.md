## The method (the same for every area)
1. **Heuristic evaluation** — Nielsen's 10 usability heuristics (NN/g) with Nielsen's severity scale 0–4.
2. **Accessibility** — WCAG 2.2 AA with axe-core under Playwright, plus the manual checks axe cannot do: keyboard reach (2.1.1),
   focus visible and not hidden (2.4.7, 2.4.11), **a single-pointer way for every drag (2.5.7)**, target size ≥ 24 px (2.5.8;
   44 px on touch), contrast (1.4.3, 1.4.11).
3. **The device matrix**, in Playwright (headless Chromium; software GL is fine for DOM, input and picking):
   mouse + keyboard at 1440×900 (DPR 1 and 2) · **touchpad**: two-finger scroll = wheel with pixel deltas on both axes
   (deltaMode 0, deltaX ≠ 0), pinch = wheel with `ctrlKey: true` (Chromium/Firefox; Safari gesture events) — both must do the
   documented thing, deltaX is never dropped · touch phone 390×844 DPR 3 (`devices['iPhone 13']`) · touch tablet 820×1180 ·
   keyboard only. Every workflow you test is walked on every row of the matrix, or the gap is a finding.
4. Fix in this order: severity 4, 3, then 2 — the **S-sized** ones in this run, one commit + one test each (vitest; jsdom for UI,
   pure functions for input maths); M/L ones go into the audit file with a sketch and a size.
