## 2026-11-13 — Monitor: agent sessions from other machines (opt-in `remoteAgents`)

- `~/.di/monitor.json` may list `remoteAgents: [{ "name": "r-di", "ssh": "r-di" }]` (max 12). For each, the Agents panel runs `ssh -o BatchMode=yes -o ConnectTimeout=3 <ssh> <fixed command>` through `runCommand`. The remote command is a constant in `monitorStore.js` (`REMOTE_SESSIONS_COMMAND`, read-only: for each `~/.claude*/sessions/*.json` whose pid is alive it prints path + the first 4 KB of JSON). Only the ssh target comes from config, and it must match `[A-Za-z0-9._@-]` and not start with `-`; nothing comes from a request.
- Rows carry `machine`, `account`, `sessionId`, `title` (session name), `status`, `cwd`, `lastActivity` (from `updatedAt`); deduped per machine+sessionId (two login dirs share one file). The panel also returns `remotes: [{name, ok, live, error?}]`; an unreachable machine shows one "not reachable" line and never greys the panel. The UI groups remote rows as `machine / account`.
