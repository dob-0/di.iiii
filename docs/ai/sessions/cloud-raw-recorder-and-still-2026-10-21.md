## 2026-10-21 — Recorder and Still: Raw keeps what the show looked like

- One of the twelve Raw features the owner approved ("yes build all 12", 2026-10-21).
- **Still** (`stream.still`, new, family send out): one PNG of a picture wire on its Take button or a rising Take signal, at the picture's own size, landed as a project file through the editor's existing upload road (`uploadProjectAsset`, or this browser's store without a project) and an `upsertAsset` op. Outputs Status, File.
- **Recorder** (`stream.recorder`, promoted off `UNIMPLEMENTED_NODE_TYPES`, relabelled from "Stream Recorder"; runtime `local` → `web`, `authoringOnly` and the dead `filePattern`/`hostHint` dropped): a picture wire, plus a sound if one is wired, to WebM between Start and Stop (buttons or rising signals). vp9 → vp8 → WebM, 6 Mbps, 30 fps. The window copies the picture into its own canvas every frame and records that canvas's `captureStream`. Outputs Recording, Seconds, Status, File, read back from the window's report through `liveOutputs`. A window closed mid-take stops and keeps the take.
- Files are named `<kind>-<source>-<date>` (`still-scene-2026-10-21T14-03-07.png`): a project file has a name and `createdAt` and no other field, so the source rides in the name. No schema change.
- **Seek contract** on the document clock (`src/project/graph/clockSeek.js`): the editor and `/out` answer `window.__seek(seconds)` (holds the clock, resolves after two animation frames, `__ready` true then) and `__play()`. `useDocumentClock` returns the held time while held.
- Vocabulary: the reserved word was **Record**; the brief named it **Recorder** — amended in `docs/ai/vocabulary.md` with a dated section. Wiki article `recorder-and-still-nodes`.
- Tests: 5 new files (`recording.test.js` 10, `clockSeek.test.js` 6, `StillPanelWindow.test.jsx` 5, `RecorderPanelWindow.test.jsx` 8, plus a held-clock case in `useDocumentClock.test.jsx`), 3 runtime cases in `nodeRuntimes.test.js`, 1 editor case in `RawEditor.test.jsx`. With the implementation stashed: 7 files fail (5 cannot import, 4 tests red).
