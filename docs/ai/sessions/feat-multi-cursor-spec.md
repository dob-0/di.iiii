## 2026-11-09 — multi-cursor and controllers spec (draft) + real-Xorg proof of two cursors

- Added `docs/design/multi-cursor-and-controllers.md`: goal, measured facts from one session on the desktop `aylmo`, a seat/slot/level model, three routes to a second cursor, a test plan with pass numbers, and open questions.
- Added `scripts/mpx-vt-test.sh`: as root, starts Xorg on VT5, makes a second master pointer, reattaches the touchpad to it, logs events per device, then returns to the starting VT by itself. Run 2 (2026-11-10, 120 s): `create-master exit=0`, `reattach exit=0`, 11079 events on the Second pointer and 37429 on the mouse side; the owner saw two cursors.
- Measured: Hyprland 0.57 on Wayland has one cursor shared by mouse and touchpad. The same `xinput create-master` made no second pointer in Xvfb or Xephyr; the cause is open. The xterm window of the test did not show (`cannot load font`); the cause is open.
- Still undone: a way to get separate cursors inside the owner's Hyprland session, the controller-list script, the agent seat, and the level service. Only the VT test script was written; no live config was touched.
- Added `scripts/cursor2/` (Form 4 prototype): grabs the touchpad, draws a second cursor with a click-through quickshell overlay, clicks by moving the real pointer there and back; `cursor2 on|off|status|dry-run`, auto-off after 60-120 s. Run 3 passed on the owner's screen (dot seen, tap and press clicked). Limit: Hyprland has one pointer, so the two cursors take turns.
