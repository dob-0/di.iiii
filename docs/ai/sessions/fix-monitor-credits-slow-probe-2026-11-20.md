## 2026-11-20 — the Monitor's Credits box no longer fails (and holds the snapshot) at the hourly slow check

- Why: the Credits block ran `di-credits status --json` under an 8 s limit. The tool keeps its probe verdicts for 3600 s and makes the real calls on the first run after that (12.1 s measured on main-desk; 2.2–2.9 s warm). So once an hour the box said "Unavailable here" and the whole snapshot waited the 8 s (snapshots of 20:42, 20:43 and 21:14 UTC on 2026-11-19 were 8.0 s each). The tool writes each route's verdict when that route's probe ends, so the same 8 s kill left a probe that was still running uncached, and every snapshot and every 30-second report started that real model call again (about 250 calls an hour on main-desk, measured by the lead chat on 2026-11-20 at 03:45). It also explains why a fresh `/admin#monitor` showed "Spaces and users" for a while: the Monitor tab appears only after the first full snapshot.
- What: `serverXR/src/monitorStore.js` keeps the last good list (`creditsMemo`) and renews it in the background; constants `CREDITS_FRESH_MS` 60 s, `CREDITS_STALE_MS` 5 min, `CREDITS_DROP_MS` 30 min, `CREDITS_WAIT_MS` 3 s, `CREDITS_COMMAND_MS` 30 s. The 30 s is the cure for the repeated calls (a cold 12.1 s run ends inside it, so every probe ends and `di-credits` writes its verdicts) and the longest the one-shot report can afford: its credits read ends at 30.5 s at the latest (the limit plus the store's 0.5 s hard cut), then git 5 s, ledger 5 s and send 15 s make 55.5 s, under the report timer's `TimeoutStartSec=60`. Panel fields: `stale`, `refreshError`, `checking`, and `checkedAt` only on an old list. Store option `creditsWaitMs`; `scripts/di/monitorReport.mjs` passes the command limit plus 2 s (a one-shot process has no earlier list). `MonitorSection.jsx`: "Checking now" note; "This list was read N ago; the latest check failed: …" or "…; a new check is running" (N is counted on the server's clock: `ago(iso, nowMs)` takes an optional clock, one argument works as before); tile "—" while checking, amber when old. Wiki: the Credits paragraph tells the three-second wait, the notes and the drop.
