## 2026-10-21 — Points: a point cloud node in Raw (Source, Count, Size, Colour)

- New node **Points** (`geom.points`, family make, render spatial-3d): one GPU `points` object standing in the scene, scattered by AREA over the surface its Source geometry wire draws. Inputs Source, Count (20,000), Size (0.02 m, attenuated), Colour, Position, Rotation; no outputs. Bare, it scatters over a 0.5 m sphere so a placed node is visible.
- The sampler moved out of the work: `src/algoVrithm/sequences/scanPoints.js` → `src/project/points/surfacePoints.js` (git mv, test moved with it; ScanCloudRoom now imports it from the platform, which the boundary test allows). Added `areaPoints` (exactly Count points, cumulative-area table + binary search), `pointBudget` (cap 120,000; 60,000 on a coarse pointer or prefers-reduced-motion — the figures the two particle-morph works settled on) and `seededRandom` (mulberry32, same as the work's `createRandom`).
- `src/project/points/geometryPoints.js` walks the descriptor with Laser Trace's `walkPieces` and builds each piece with its `meshOf` (now exported), so the cloud lies on the same mesh the viewport draws. A Line has no surface and gives no points — the first test run caught it crashing `meshOf` and it is skipped before that.
