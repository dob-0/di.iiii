# Words

> One word, one meaning. These are the words a person reads in di.iiii, each with the one job it does. An assistant answering about di.iiii should use them the same way.

The full dictionary, with the reasons behind each word and the words that are banned, is in the source: [docs/ai/vocabulary.md](https://github.com/dob-0/di.iiii/blob/dev/docs/ai/vocabulary.md). This page is the short public part of it; a test keeps every word here in that dictionary.

## The dictionary

- **di.iiii**: the whole thing. Spaces live in it.
- **space**: a place that is yours: an address, a guest list, and everything in it.
- **project**: one thing you make inside a space.
- **scene**: the 3D place you can be inside.
- **object**: one thing standing in the scene.
- **canvas**: the surface your nodes sit on.
- **node**: one card on the canvas.
- **page**: a published web page (HTML/CSS/JS), never a project.
- **Studio**: the one you walk into for the four editing panels.
- **Nodes**: the node canvas, the tool where a project's nodes are wired together.
- **Projection**: the tool that puts a project on a wall.
- **work**: what the public meets: a title, an author, an address. The same object a project names backstage.
- **place**: a real room in the world: walls, a rig, an audience, a date. A space may be its twin; it can never be it.
- **production**: a place, a client, a work and a run. What the studio makes. It uses di.iiii; it does not live in it.
- **view**: a named camera a project keeps, a button that takes you there.
- **lamp**: a stage fixture, the real device on the rig.
- **light**: a 3D scene light: the sun, a point, a spot, an ambient light.
- **team**: the members of a space, said as one word where a page has to name them to a guest.

## Two names

- **di.iiii** is the product. Inside the product, it is always di.iiii.
- **di.i** is the studio that makes it: correct on a byline and at thedi.studio, never as the product's name.
