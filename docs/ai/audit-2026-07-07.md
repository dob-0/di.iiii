## High

- ☐ **Dead camera-controls ref breaks five Studio features** — `StudioEditor.jsx:183` creates a
  `controlsRef` that is never the one `StudioViewportLayout.jsx:81` attaches to the canvas.
  Save-current-view persists stale data, Editor's Frame-Selected is unreachable, double-click
  placement falls back to ring layout, XR exit never restores the camera, saved default view is
  never applied on load. Fix: thread one ref (or a shared registration like `fitToSelectionRef`)
  from the layout up; add a test that the ref is populated after mount.
- ☑ **Shift+D duplicated twice per keypress** (double keydown registration Editor+Shell) — fixed
  in this session, see known-fixes row.
- ☑ **Gizmo icons rendered as mojibake** (`GizmoModeButtons.jsx` double-encoded UTF-8) — fixed in
  this session, see known-fixes row.
- ☐ **Client-only admin mode flips edit gating with no server regression test** —
  `useAppState.js:265` (`canEditScene = !isReadOnly || isAdminMode`), hidden gestures in
  `useEditorShortcuts.js` / `useSceneActions.js`. Assumed safe because serverXR 403s the writes —
  add a contract test pinning that 403 for read-only spaces.
- ☐ **WASM-OOM bug class reintroduced in sync routes** — `serverXR/src/routes/syncRoutes.js:18`
  still uses global `fetch`; the GitHub-sync path was migrated off it because undici's WASM
  parser OOMs under cPanel/LVE limits (own known-fixes row). Reuse that client here.
- ☐ **schema-sync test doesn't compare ESM vs CJS** — `serverXR/src/schemaSync.test.js` only
  checks `shared/projectSchema.cjs` against hardcoded invariants; an ESM edit that skips the
  hand-mirror still passes the pre-push gate. Better end state: generate the CJS mirror from the
  ESM source at build time and delete the hand-mirror workflow (and its Edit-hook warning).
- ☐ **Asset delete-protection ignores legacy V1 scene refs** — `spaceRoutes.js` (~739) scans
  project documents only; `spaceStore.js` already has the V1 scene-ref enumerator to include.

  line below is escaped; mirror that).
- ☐ `push-wcc-projects.mjs:59` silently defaults to **staging** while its docstring says

  OAuth callbacks, sync-key minting, uploads.
