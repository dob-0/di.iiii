## High

- ☑ **Dead camera-controls ref broke five Studio features** (save-current-view, frame-selected,
  double-click placement, XR camera restore, saved-view-on-load) — StudioEditor's `controlsRef`
  is now a live proxy over the active pane's registered camera-controls
  (`shared.paneControlsRef`, same pattern the old `fitToSelectionRef` used); the perspective view
  opens on the project's saved view; F/"." is owned by StudioEditor alone (shell's duplicate
  binding removed). Guard: `StudioViewportLayout.test.jsx`.
- ☑ **Shift+D duplicated twice per keypress** — StudioShell's duplicate keydown bindings removed;
  guards in `StudioShell.test.jsx`. See known-fixes row.
- ☑ **Gizmo icons rendered as mojibake** — real glyphs + `GizmoModeButtons.test.jsx`. See
  known-fixes row.
- ☐ **Client-only admin mode flips edit gating with no server regression test** —
  `useAppState.js:265` (`canEditScene = !isReadOnly || isAdminMode`), hidden gestures in
  `useEditorShortcuts.js` / `useSceneActions.js`. Assumed safe because serverXR 403s the writes —
  add a contract test pinning that 403 for read-only spaces.
- ☑ **WASM-OOM bug class reintroduced in sync routes** — `syncRoutes.js` now uses
  `httpClient.js` (node:https), and a new contract test bans global `fetch` in all serverXR
  source so the class can't ship a third time.
- ☐ **schema-sync test doesn't compare ESM vs CJS** — `serverXR/src/schemaSync.test.js` only
  checks `shared/projectSchema.cjs` against hardcoded invariants; an ESM edit that skips the
  hand-mirror still passes the pre-push gate. Better end state: generate the CJS mirror from the
  ESM source at build time and delete the hand-mirror workflow (and its Edit-hook warning).
- ☑ **Asset delete-protection ignored legacy V1 scene refs** — the delete guard now also scans
  the space's `scene.json` via `collectSceneAssetRefs`; 409 reports `Space scene (V1)` usage.
  Contract test added.

## Medium

  revisit only if it ever hosts third-party content.
- ☑ Drive `folderId` is now quote-escaped in the `q` filter, matching the `query` param.
- ☑ `push-wcc-projects.mjs` docstring now states the real default (staging, deliberate;
  production requires an explicit `--to`).
- ☑ A dropped socket now schedules a reconnect (plain `disconnect` takes the same retry path as
  `connect_error`; own cleanup is excluded). Guard in `useSpaceSocket.test.js`.
- ☑ Portal traversal uses the shared `appNavigate` helper — no more full reload per jump.
- ☑ `AUTH_SESSION_SECRET` fallback to a bearer token now logs a loud startup warning naming the

  aware): guest-session issuance, login, OAuth start/callback, sync-key minting, uploads.
  Guards: `rateLimit.test.js` + a 429 login contract test.
