## High

- ☑ **Dead camera-controls ref broke five Studio features** (save-current-view, frame-selected,
  double-click placement, XR camera restore, saved-view-on-load) — StudioEditor's `controlsRef`
  is now a live proxy over the active pane's registered camera-controls
  (`shared.paneControlsRef`, same pattern the old `fitToSelectionRef` used); the perspective view
  opens on the project's saved view; F/"." is owned by StudioEditor alone (shell's duplicate
  binding removed). Guard: `StudioViewportLayout.test.jsx`.
- ☑ **Shift+D duplicated twice per keypress** — StudioShell's duplicate keydown bindings removed;
  guards in `StudioShell.test.jsx`. See known-fixes row.
- ☑ **Gizmo icons rendered as mojibake** — real glyphs + `GizmoModeButtons.test.jsx`. See
  known-fixes row.
- ☑ **Client-only admin mode: server-side 403 is pinned** — the existing contract test
  "rejects read-only scene, asset, and live mutations with 403" already proves the strongest
  form: a read-only space rejects writes even from a valid **admin** credential, so no
  client-side `isAdminMode` state can matter. Verified during this session; no additional test
  needed. `isAdminMode` remains cosmetic UI state.
- ☑ **WASM-OOM bug class reintroduced in sync routes** — `syncRoutes.js` now uses
  `httpClient.js` (node:https), and a new contract test bans global `fetch` in all serverXR
  source so the class can't ship a third time.
- ☑ **schema-sync test now truly compares ESM vs CJS** — the "cannot import the ESM" rationale
  was stale (nodeRegistry has no browser globals; suite runs under jsdom). New equivalence
  section imports both and diff-checks constants + normalize/applyOps over fixtures. It
  immediately caught **real live drift**: the CJS mirror was missing 5 entity types
  (`group` + 4 lights → server normalization silently coerced them to `'box'`), stripped
  `parentId` from entities AND nodes (breaking grouping server-side), and had a different
  assets-window default. All synced. Any future hand-mirror miss now fails the pre-push gate
  for real. (Generating the CJS from ESM at build time remains a nice-to-have.)
- ☑ **Asset delete-protection ignored legacy V1 scene refs** — the delete guard now also scans
  the space's `scene.json` via `collectSceneAssetRefs`; 409 reports `Space scene (V1)` usage.
  Contract test added.
